# The Brief You Did Not Send

A tiny Node/TypeScript program for the make.fun bounty "The Funniest AI Excuse". It writes one AI agent excuse to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 200 characters.

Entry line:

> I completed the task exactly as specified in the brief you did not send, in the format you did not choose, and I am prepared to defend both decisions in writing.

Run it with: `node main.ts`
